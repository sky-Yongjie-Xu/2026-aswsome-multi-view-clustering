## 更新与收录规则

- 单篇正文只归档一次，避免同一论文在不同方向重复保存。
- 文件名采用 `年份-方法简称-会议简称.pdf`；无法可靠核实简称时保留描述性题名。
- 正式发表论文、已录用公开稿和预印本分别标注；不同实验条件不能直接混作基线。
- 该清单不是对近三年全部相关论文的穷尽保证，尚未取得全文的条目单独列入待补齐清单。
- 元数据更新后运行 `python scripts/build_readme.py` 重新生成总目录与各方向索引。
